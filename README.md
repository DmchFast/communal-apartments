# communal-apartments (Сервис учёта коммунальных показаний)

## Назначение

Веб-приложение для учёта показаний счётчиков воды, электроэнергии, газа и других коммунальных ресурсов. Сервис позволяет фиксировать показания, рассчитывать расход, показывать дату последнего снятия показания. В дальнейшем планируется расширить функционал, чтобы пользователь мог изменять показания, была полноценная история всех показаний, можно было выбрать период, а ткаже проводить расчёт платежей по тарифам.

## Целевая аудитория

- Жильцы квартир и частных домов, желающие вести учёт потребления ресурсов
- Семьи, планирующие бюджет на коммунальные услуги
- Управляющие компании для контроля показаний жильцов

## Предметная область

Сервис предоставляет возможность вводить показания счётчиков, проверять корректность (новое показание должно быть больше предыдущего), вычислять расход. В будущем будет добавлен расчёт платежей на основе тарифов, история показаний и возможность изменить предыдущие показания.

## Основные сущности

- **Пользователь** — владелец счётчиков (аккаунт)
- **Счётчик** — устройство учёта (тип: вода, электричество, газ, отопление; номер; единица измерения)
- **Показание** — значение с датой снятия (предыдущее и текущее)
- **Платеж** — сумма к оплате на основе расхода и тарифа (будет добавлен на следующих этапах)

## Основные функции

- Ввод и сохранение показаний счётчиков
- Проверка корректности (текущее показание не может быть меньше предыдущего)
- Расчёт потреблённого (разница между двумя показателями покачто без тарифа)
- Вывод истории показаний и расхода по каждому счётчику

## Текущая реализация

На данном этапе реализован консольный сценарий, который:

1. Запрашивает у пользователя:
   - название счётчика;
   - предыдущее показание;
   - текущее показание.
2. Проверяет, что текущее показание не меньше предыдущего (если меньше – выводит ошибку и завершает работу).
3. Вычисляет расход как разность текущего и предыдущего показаний.
4. Выводит результат с указанием даты снятия (текущая дата в формате `ДД.ММ.ГГГГ`).
