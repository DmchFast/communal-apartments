# communal-apartments (Сервис учёта коммунальных показаний)

## Назначение

Веб-приложение для учёта показаний счётчиков воды, электроэнергии, газа и других коммунальных ресурсов. Сервис позволяет фиксировать показания, рассчитывать расход, показывать дату последнего снятия показания. В дальнейшем планируется расширить функционал, чтобы пользователь мог изменять показания, была полноценная история всех показаний, можно было выбрать период, а ткаже проводить расчёт платежей по тарифам.

## Целевая аудитория

- Жильцы квартир и частных домов, желающие вести учёт потребления ресурсов
- Семьи, планирующие бюджет на коммунальные услуги
- Управляющие компании для контроля показаний жильцов

## Предметная область

Сервис предоставляет возможность добавлять счётчики, вносить показания с автоматической фиксацией даты и времени, проверять корректность (новое показание не может быть меньше предыдущего), вычислять расход как разность двух последних показаний и рассчитывать платёж по установленному тарифу. Данные каждого пользователя хранятся в отдельных JSON-файлах.

## Основные сущности

- **Пользователь** — владелец счётчиков (вход по имени)
- **Счётчик** — устройство учёта (название, единица измерения, тариф)
- **Показание** — значение с датой и временем снятия
- **Платёж** — сумма к оплате на основе расхода и тарифа

## Основные функции

- Вход в профиль по имени пользователя
- Просмотр списка всех счётчиков с указанием тарифа
- Добавление счётчиков (название, единица измерения)
- Внесение показаний с автоматической фиксацией даты и времени
- Просмотр истории показаний по каждому счётчику
- Расчёт расхода между двумя последними показаниями
- Установка тарифа (можно оставить пустым/пробел - тариф не устанавливается)
- Расчёт платежа в рублях (требуется установленный тариф)

## Структура проекта

- `main.py` — точка входа, меню и обработчики пунктов
- `meters.py` — функции работы со счётчиками (добавление, вывод списка)
- `readings.py` — функции работы с показаниями (добавление, история, расчёт расхода)
- `tariffs.py` — функции работы с тарифами (установка, расчёт платежа)
- `storage.py` — сохранение и загрузка данных в JSON (контекстные менеджеры)
- `utils.py` — вспомогательные функции безопасного ввода
- `data/` — JSON-файлы данных (отдельно для каждого пользователя)
- `tests/` — автоматизированные тесты pytest (будет добавлено)
- `README.md` — документация проекта
- `requirements.txt` — зависимости проекта

## Формат хранения данных

Данные хранятся в формате JSON в каталоге `data/`. Для каждого пользователя создаются отдельные файлы:
- `data/meters.json` — счётчики пользователя
- `data/readings.json` — показания пользователя

Пример записи счётчика:
```json
{
  "Пользователь": {
    "1": {
      "name": "Вода",
      "unit": "м^3",
      "tariff": 45.5
    }
  }
}
```
Пример записи показания:
```json
{
  "Пользователь": [
    {
      "meter_id": 1,
      "value": 2324.0,
      "date": "2026-09-15",
      "time": "08:32:37"
    }
  ]
}
```

## Текущая реализация

Текущая реализация
На данном этапе реализовано консольное приложение с меню из 7 пунктов:

1. Показать счётчики
2. Добавить счётчик
3. Внести показание
4. История показаний
5. Рассчитать расход
6. Установить тариф
7. Рассчитать платёж
8. Выход

Программа проверяет корректность ввода, обрабатывает исключения, сохраняет данные в JSON и загружает их при запуске.

## Запуск

```bash

cd communal-apartments

# Активация виртуального окружения
.venv\Scripts\activate

# Установка зависимостей
python -m pip install -r requirements.txt

# Запуск программы
python main.py
```
